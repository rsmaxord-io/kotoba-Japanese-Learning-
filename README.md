# Kotoba — Japanese Learning

550 lessons from Foundation to N1-level material, with reading, listening, writing, speaking, Culture Quests, a bilingual dictionary, and a Sound Atlas with 72 native-recorded examples.

Static HTML, CSS and JavaScript: no build step. Open `index.html` through a web server. Progress and drafts stay in the learner’s browser.

## Credits

Third-party recordings and dictionary data retain their own licenses. See `discovery-data/CREDITS.md`, `dictionary/README.md`, and the source/license links in the app. Some dialect recordings are licensed for noncommercial use. Hokkaido recordings stream from their university source and require an internet connection.

Standard course audio is synthesized. Regional recordings represent the named speakers and localities.
